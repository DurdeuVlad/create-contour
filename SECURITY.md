# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x alphas | yes |
| 0.1.x alphas | no - upgrade |

## Reporting a vulnerability

Do **not** open a public issue for exploitable problems (world corruption,
crashes crafted by remote players, item/material duplication, ledger
exploits).

Report privately via GitHub's
[private vulnerability reporting](https://github.com/DurdeuVlad/create-contour/security/advisories/new)
or by contacting the maintainer through the profile at
https://github.com/DurdeuVlad.

Include: mod version, Minecraft/NeoForge/Create versions, reproduction
steps, and whether a server or client is affected. You will get a triage
answer before any public disclosure.
